# RPUF
In the modern era, integrated circuits (ICs) face escalating threats including sophisticated attacks, thirdparty foundry compromises, and reverse engineering. These vulnerabilities underscore the necessity for
robust security solutions to safeguard sensitive hardware. Physical Unclonable Functions (PUFs) emerge
as essential hardware security primitives, generating unique identifiers based on inherent physical
variations. However, the rising threat of Machine Learning (ML) attacks poses a significant challenge to
the security of traditional PUF implementations. As attackers increasingly employ ML techniques to
predict and replicate PUF responses, the vulnerability of these systems escalates, potentially undermining
their reliability and security. In this project,  a novel approach is proposed to fortify PUFs against ML
attacks through the implementation of Elliptic Curve Cryptography (ECC) encryption. By leveraging
ECC's strong security features and lower computational requirements, it is aim to encrypt the
communication and data involving PUFs, ensuring that even if adversaries analyze intercepted data using
ML techniques, they are thwarted from deciphering the unique identifiers or exploiting them for
unauthorized access or cloning
